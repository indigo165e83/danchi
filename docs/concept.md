# バーチャル団地くらし

## コンセプト

仮想の団地に住んで、住人とゆるくつながる。

## 要件

要件IDは、テスト条件や Pest のテスト名からも参照する（トレーサビリティ確保のため）。

| ID | 要件 |
|---|---|
| REQ-01 | 住人は団地に自分の部屋をもっている |
| REQ-02 | 住人は自分のアイテムを持っている |
| REQ-03 | 自分の部屋やみんなの花壇で、花や作物を育てられる |
| REQ-04 | 現実と同じ時間が流れ、花や作物も現実と同じタイミングで咲いたり収穫できる |
| REQ-05 | AI の住人がいて、挨拶や軽い会話ができる |

## 開発の段階

| 段階 | 内容 | 関連要件 |
|---|---|---|
| 1 | 自分の部屋＋鉢植え1つ（植えた時刻から成長段階を表示） | REQ-01, REQ-03, REQ-04 |
| 2 | 複数住人と共有花壇 | REQ-03 |
| 3 | AI 住人との挨拶 | REQ-05 |
| 4 | アイテム収集・季節イベント・通知 | REQ-02, REQ-04 |

## 設計上の方針（構想段階）

- 成長段階は「植えた時刻」だけを保存し、表示時に経過時間から計算する（常時計算しない）
- 成長の計算はサーバー側で行う（端末の時計変更による不正を防ぐ）
- AI 住人の呼び出しは必ずサーバー経由とし、1日の会話回数に上限を設ける（APIキー保護と費用管理）
- 共有花壇は「完全なリアルタイム」でなくてよい。最初はポーリングや足跡表示で十分
- 住人同士のメッセージ機能を入れる場合は、通報・ブロックなどのモデレーションも必要。最初は定型の挨拶やスタンプのみにする
