# 0004: ライセンスに AGPL-3.0-or-later を採用する

- 日付：2026-10-04
- 状態：決定

## 背景

OSS として公開し、将来は有志の参加を受け入れたい。可能なら収益化もしたい。

## 検討した選択肢

1. MIT
2. AGPL（AGPL-3.0-or-later）
3. ソース公開型（FSL など）
4. 非公開

## 決定

2 を採用する。リポジトリ直下の [LICENSE](../../LICENSE) に全文を置く。

## 理由

- Web サービスでは、改変版を閉じた形で運営されることを防げるのは AGPL である
- 正式な OSS なので、有志も参加しやすい
- 収益はコードではなく公式サービスの運営から生まれるため、コードを公開しても成り立つ
- 厳しいライセンスから始めれば、後から緩める選択肢を残せる

## 影響

- 参加者の受け入れを始めるときに CLA を導入する
- 収益化が見えてきたら、名前の商標や利用規約を検討する
