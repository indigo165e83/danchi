# 非機能要件と制約

## 非機能要件

| ID | 要件 |
|---|---|
| REQ-NFR-01 | 成長段階は「植えた時刻」から表示時に計算する（常時計算しない） |
| REQ-NFR-02 | 成長段階はサーバー側で計算し、端末の時計を変更しても早く育たない |
| REQ-NFR-03 | AI 住人の呼び出しはサーバー経由とし、1日の会話回数に上限を設ける（APIキーの保護と費用管理） |
| REQ-NFR-04 | スマホのブラウザで快適に操作できる |

## 制約

- Laravel 13 ＋ Inertia ＋ React、MariaDB で構築する（[ADR-0001](../adr/0001-laravel-vite-react.md)）
- WebSocket やキューの常駐が必要なため、本番は VPS 以上で運用する
